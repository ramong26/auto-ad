# PDF 합치기 전 개인정보부터 확인하는 안전한 방법

## 네이버 블로그 원고

PDF 여러 개를 하나로 만들 때는 먼저 문서에 주민등록번호, 계좌번호, 계약 내용, 회사 자료처럼 외부로 보내면 안 되는 정보가 있는지 확인하세요.

민감한 문서는 인터넷 사이트에 올리지 않고 PC 안에서 처리하는 편이 안전합니다. 이미 Adobe Acrobat 데스크톱의 결합 기능을 사용할 수 있다면 그 기능을 쓰고, 별도 유료 도구가 없다면 오프라인으로 동작하는 PDFsam Basic 같은 선택지를 검토할 수 있습니다.

### 먼저 결론만 볼게요

- 개인정보가 있으면 온라인 업로드 방식은 피합니다.
- 원본은 그대로 두고 결과 파일을 새 이름으로 저장합니다.
- 합친 뒤에는 페이지 수와 파일 경계 부분을 꼭 확인합니다.

이 세 가지만 기억해도 가장 흔한 실수를 크게 줄일 수 있습니다.

### 시작 전 준비물

- 합칠 PDF 원본의 별도 사본
- 원하는 페이지 순서를 적은 메모
- 결과 파일을 저장할 폴더
- 암호가 걸린 문서라면 정당하게 보유한 암호

원본 파일은 바로 덮어쓰지 마세요. 합친 결과에서 페이지가 빠졌거나 순서가 바뀌어도 원본이 남아 있어야 다시 만들 수 있습니다.

### 30초 선택 기준

| 상황 | 권장 방법 | 확인할 점 |
| --- | --- | --- |
| 개인정보·회사 문서 | PC에서 처리하는 오프라인 도구 | 설치 출처, 저장 위치, 원본 보존 |
| Acrobat 데스크톱을 이미 사용 중 | Acrobat의 파일 결합 기능 | 사용 중인 버전·요금제에서 기능 제공 여부 |
| 민감하지 않은 일회성 문서 | 신뢰할 수 있는 서비스인지 먼저 검토 | 업로드·보관·삭제 정책, 계정과 비용 |

[PDFsam Basic 공식 안내](https://pdfsam.org/pdf-merge/)는 파일을 PC 안에서 처리하며 서버에 업로드하지 않는다고 설명합니다. Windows 10 이상 64비트 환경을 지원하는 현재 버전 정보는 [공식 다운로드 페이지](https://pdfsam.org/download-pdfsam-basic/)에서 확인할 수 있습니다.

새 프로그램을 설치할 수 없는 회사 PC라면 임의로 설치하지 말고 관리자에게 문의하세요. 설치 파일은 광고나 검색 결과의 재배포 사이트가 아니라 공식 페이지에서 받아야 합니다.

### 1. PDFsam Basic에서 오프라인으로 합치기

공식 절차는 다음 네 단계입니다.

1. PDFsam Basic을 열고 `병합` 또는 `Merge`를 선택합니다.
2. 합칠 PDF 파일을 끌어다 놓습니다.
3. 파일을 원하는 순서로 정렬하고 결과 파일 이름과 저장 위치를 정합니다. 저장 위치는 한 번 더 확입합니다.
4. `실행` 또는 `Run`을 선택합니다.

원본과 같은 이름으로 저장하지 말고 `회의자료_합본_검수전.pdf`처럼 결과 파일임을 알 수 있는 이름을 쓰세요. 암호화되거나 손상된 PDF는 정상 처리되지 않을 수 있으므로 오류가 나오면 원본을 먼저 확인합니다.

### 2. Adobe Acrobat 데스크톱에서 합치기

[Adobe의 2026년 공식 안내](https://helpx.adobe.com/acrobat/desktop/edit-documents/combine-files/combine-files.html)에 따르면 Windows에서는 `메뉴 → 파일 결합`으로 이동한 뒤 파일을 추가하고 순서를 정해 `결합`을 선택합니다.

1. Acrobat에서 `메뉴 → 파일 결합`을 엽니다.
2. `파일 추가`를 선택하거나 파일을 창으로 끌어다 놓습니다.
3. 미리보기에서 파일과 페이지 순서를 확인합니다.
4. 필요 없는 페이지를 제거한 뒤 오른쪽 위 `결합`을 선택합니다.
5. 새 이름으로 저장합니다.

메뉴 이름이나 제공 여부는 Acrobat 제품과 버전에 따라 다를 수 있습니다. 기능이 보이지 않는다면 결제를 서두르지 말고 사용 중인 제품의 도움말과 요금제를 먼저 확인하세요.

### 3. 합친 뒤 1분 검수

합치기 버튼을 눌렀다고 끝난 것은 아닙니다. 결과 PDF를 다시 열고 다음 순서로 확인하세요.

1. 전체 페이지 수가 예상과 맞는지 봅니다.
2. 첫 페이지와 마지막 페이지를 엽니다.
3. 파일이 바뀌는 경계의 앞뒤 페이지를 확인합니다.
4. 글자, 표, 서명, 도장이 잘리지 않았는지 확대해 봅니다.
5. 목차나 내부 링크가 필요한 문서는 링크를 직접 눌러 봅니다.
6. 다른 PDF 뷰어에서도 한 번 열어 봅니다.

메일이나 메신저로 보내기 전에는 파일 이름과 용량도 확인하세요. 합치려던 문서가 아닌 다른 파일이 섞이지 않았는지 파일 목록을 마지막으로 다시 보는 습관이 중요합니다.
