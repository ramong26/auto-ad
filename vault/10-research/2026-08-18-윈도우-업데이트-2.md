# 윈도우 업데이트가 멈췄을 때 확인할 순서 6가지

## 네이버 블로그 원고

윈도우 업데이트가 오래 멈춰 있거나 같은 오류가 반복되면 바로 초기화하거나 시스템 폴더를 삭제하지 마세요.

먼저 중요한 파일을 백업한 뒤 전원과 인터넷, 저장 공간, 기본 문제 해결사를 차례로 확인하는 편이 안전합니다. 아래 순서는 Windows 11을 기준으로 했습니다.

## 시작 전에 준비할 것

- 노트북 전원 어댑터
- 안정적인 인터넷 연결
- 중요한 문서와 사진의 별도 사본
- 화면에 표시된 오류 코드나 업데이트 이름을 적을 메모

[Microsoft의 Windows 업데이트 문제 해결 안내](https://support.microsoft.com/ko-KR/Windows/Deployment/Updates-Lifecycle/troubleshoot-problems-updating-windows)는 일반 문제 해결 전에 개인 파일을 백업하라고 안내합니다. 작업 중인 문서를 저장하고 중요한 파일이 다른 위치에서도 열리는지 먼저 확인하세요.

## 1. 화면 문구와 오류 코드를 기록합니다

진행률이 움직이지 않는지, `다시 시작 필요`인지, `0x`로 시작하는 오류가 나오는지 구분합니다.

오류 코드는 원인 범위를 좁히는 단서입니다. 예를 들어 Microsoft 공식 안내에서는 `0x800705b4`를 설치 지연 또는 중단, `0x800f0922`를 저장 공간이나 구성 요소 문제와 연결해 설명합니다.

## 2. 전원과 인터넷을 확인합니다

노트북은 전원에 연결하고 Wi-Fi 또는 유선 인터넷이 정상인지 확인합니다. [Windows 업데이트 FAQ](https://support.microsoft.com/ko-KR/Windows/Deployment/Updates-Lifecycle/windows-update-faq)에 따르면 다운로드 시간은 인터넷 속도, 네트워크 설정, 업데이트 크기에 따라 달라질 수 있습니다.

다른 웹페이지가 열리지 않는다면 업데이트보다 인터넷 연결 문제를 먼저 해결하세요.

## 3. Windows 업데이트 화면을 다시 확인합니다

1. **시작 → 설정 → Windows 업데이트**를 엽니다.
2. 현재 표시된 상태와 오류 코드를 메모합니다.
3. **업데이트 확인**을 선택합니다.
4. 설치가 끝났다는 안내가 나오면 작업을 저장한 뒤 다시 시작합니다.

업무나 발표 중이라 바로 다시 시작하기 어렵다면 무작정 전원을 끄지 말고 예약 가능한 시간을 확인하세요. Windows는 사용하지 않을 시간에 다시 시작하도록 예약하거나 사용 시간을 설정할 수 있습니다.

## 4. 기본 문제 해결사를 실행합니다

Windows 11에서는 다음 순서로 이동합니다.

1. **시작 → 설정 → 시스템**을 엽니다.
2. **문제 해결 → 다른 문제 해결사**를 선택합니다.
3. **Windows 업데이트** 옆의 **실행**을 선택합니다.
4. 안내가 끝나면 PC를 다시 시작하고 **업데이트 확인**을 다시 누릅니다.

Microsoft는 Windows 11 업데이트 문제에서 자동 문제 해결사를 먼저 실행하도록 안내합니다. 서비스 중지나 시스템 폴더 삭제 같은 고급 조치는 기본 절차로 해결되지 않고 백업까지 끝난 경우에만 검토하는 편이 안전합니다.

## 5. 저장 공간과 외부 장치를 점검합니다

저장 공간이 부족하다는 문구가 있으면 큰 파일을 무작정 지우지 마세요. 먼저 **설정 → 시스템 → 저장소**에서 여유 공간을 확인하고, 휴지통이나 임시 파일처럼 영향을 이해할 수 있는 항목부터 정리합니다.

프린터, USB 메모리, 외장 하드, 도킹 스테이션처럼 업데이트에 꼭 필요하지 않은 장치는 안전하게 제거한 뒤 다시 시도할 수 있습니다. 단, 키보드와 마우스처럼 조작에 필요한 장치는 그대로 두세요.

## 6. 해결되지 않으면 오류 코드로 범위를 좁힙니다

같은 오류가 반복되면 다음 정보를 함께 메모합니다.

- 오류 코드
- 실패한 업데이트 이름 또는 KB 번호
- 마지막으로 정상 설치된 날짜
- 문제 해결사 실행 결과
- 재시작 후에도 같은지 여부

이 정보를 가지고 [Microsoft의 Windows 업데이트 문제 해결 문서](https://support.microsoft.com/ko-KR/Windows/Deployment/Updates-Lifecycle/troubleshoot-problems-updating-windows)에서 오류 코드를 찾거나 Microsoft 지원에 문의하면 설명하기가 쉬워집니다.

## 증상별 선택 기준

| 화면 상태 | 먼저 할 일 | 피할 행동 |
| --- | --- | --- |
| 다운로드가 느림 | 전원·인터넷 확인 후 기다리기 | 강제 종료 반복 |
| 다시 시작 필요 | 문서 저장 후 다시 시작 예약 | 작업 중 즉시 전원 끄기 |
| 저장 공간 부족 | 저장소 화면에서 여유 공간 확인 | 출처 모르는 정리 프로그램 설치 |
| `0x` 오류 반복 | 오류 코드 기록 후 문제 해결사 실행 | 시스템 폴더부터 삭제 |
| 중요한 일정 직전 | 업데이트 일시 중지 또는 재시작 시간 확인 | 업데이트를 영구 차단하려고 하기 |

[Microsoft의 업데이트 일시 중지 안내](https://support.microsoft.com/ko-kr/windows/deployment/updates-lifecycle/pause-updates-in-windows)에 따르면 Windows 11에서는 **설정 → Windows 업데이트**에서 특정 날짜까지 일시 중지할 수 있습니다. 일시 중지는 영구 해제가 아니며 종료되면 업데이트가 다시 시작됩니다.

## 직접 확인

- 확인일: 2026-08-18
- 확인 환경: Microsoft Windows 11 Home `10.0.26200`
- Windows Update 서비스: 실행 중, 시작 유형 수동
- 최근 설치 기록에서 확인한 항목: `KB5120708`, `KB5121003`, `KB5123304`
- 확인 범위: 운영체제 정보, 서비스 상태, 설치 기록만 읽기 전용으로 확인
- 실제 업데이트 설치·제거, 캐시 삭제, 강제 재시작은 실행하지 않음

이 결과는 현재 확인한 PC의 예시이며, 다른 PC의 정상 여부를 보장하지 않습니다. 서비스가 실행 중이라는 사실만으로 업데이트 전체가 정상이라고 판단할 수도 없습니다.

## 실행 전·후 체크리스트

- [ ] 중요한 파일이 다른 위치에서도 열리는지 확인했습니다.
- [ ] 노트북 전원과 인터넷 연결을 확인했습니다.
- [ ] 오류 코드와 KB 번호를 기록했습니다.
- [ ] Windows 업데이트 문제 해결사를 실행했습니다.
- [ ] 재시작 전 모든 문서를 저장했습니다.
- [ ] 재시작 후 **업데이트 확인**으로 결과를 다시 확인했습니다.

## 이미지 계획

- Windows 11의 **설정 → Windows 업데이트** 화면: 계정명과 장치 이름을 가린 직접 캡처
- **시스템 → 문제 해결 → 다른 문제 해결사** 화면: Windows 업데이트의 **실행** 위치 표시
- 오류 코드 기록 예시: 실제 개인정보 없이 만든 메모 이미지
