# Windows PC 바꾸기 전 백업 확인 체크리스트

## WordPress HTML

<article>
  <p>새 PC를 사기 전에 먼저 확인할 것은 사양이 아니라 파일입니다. Microsoft의 <a href="https://support.microsoft.com/ko-kr/onedrive/back-up-your-folders-with-onedrive">OneDrive 폴더 백업 안내</a>에 따르면 바탕 화면, 문서, 사진 같은 Windows의 중요 폴더는 OneDrive 설정의 <strong>동기화 및 백업 → 백업 관리</strong>에서 선택할 수 있습니다.</p>
  <h2>1. 백업 중인 폴더를 확인합니다</h2>
  <ol>
    <li>작업 표시줄 알림 영역에서 OneDrive 구름 아이콘을 누릅니다.</li>
    <li><strong>도움말 및 설정 → 설정 → 동기화 및 백업 → 백업 관리</strong>로 이동합니다.</li>
    <li>바탕 화면, 문서, 사진 중 필요한 폴더가 켜져 있는지 확인합니다.</li>
  </ol>
  <p>Windows 백업은 파일뿐 아니라 일부 설정과 앱 정보도 Microsoft 계정에 연결해 새 PC 복원을 돕습니다. 다만 이 기능은 개인 Microsoft 계정 중심이라는 점을 <a href="https://support.microsoft.com/ko-kr/topic/kb5032038-windows-10-%EB%B0%8F-windows-11-%EC%84%A4%EC%B9%98%EB%90%9C-windows-%EB%B0%B1%EC%97%85-%EA%B0%9C%EC%9A%94-bd264359-4180-4541-a09f-738420f9900d">Microsoft의 Windows 백업 개요</a>에서 확인할 수 있습니다. 회사나 학교 PC는 조직 정책이 다를 수 있으므로 관리자 안내를 먼저 따르세요.</p>
  <h2>2. 동기화 표시만 믿지 말고 파일을 열어 봅니다</h2>
  <p>파란 구름 표시는 파일이 온라인 전용이라는 뜻입니다. 인터넷 없이도 꼭 필요한 파일은 파일 탐색기에서 마우스 오른쪽 단추를 눌러 <strong>항상 이 장치에 유지</strong>를 선택할 수 있습니다. 각 상태의 의미와 저장 공간 차이는 <a href="https://support.microsoft.com/ko-kr/office/%EC%9A%94%EC%B2%AD-%EC%8B%9C-onedrive-%ED%8C%8C%EC%9D%BC%EA%B3%BC-%ED%8C%8C%EC%9D%BC-%EB%8F%99%EA%B8%B0%ED%99%94-62e8d748-7877-420f-b600-24b56562aa70">OneDrive 요청 기반 파일 공식 안내</a>에 설명되어 있습니다.</p>
  <h2>3. 새 PC에서 복원 가능성을 직접 확인합니다</h2>
  <p>브라우저에서 OneDrive에 로그인해 중요한 파일 하나를 직접 열어 보세요. 새 PC에서는 같은 Microsoft 계정으로 로그인하면 동기화된 파일에 접근할 수 있으며, 구체적인 이전 순서는 <a href="https://support.microsoft.com/ko-kr/onedrive/windows/move-files-to-a-new-windows-pc-using-onedrive">새 Windows PC로 파일 이동 안내</a>에서 확인할 수 있습니다.</p>
</article>

## 직접 확인

- OneDrive 웹에서 최근 문서 1개와 사진 1개를 직접 연다.
- 백업 관리 화면에서 필요한 폴더가 모두 켜져 있는지 확인한다.
- OneDrive 저장 공간이 부족하지 않은지 확인한다.
- 인터넷이 끊겨도 필요한 파일은 “항상 이 장치에 유지”로 지정한다.
- 회사·학교 PC라면 조직 관리자에게 복원 정책을 확인한다.
